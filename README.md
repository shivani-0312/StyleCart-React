# StyleCart – React E-commerce Shopping Interface

StyleCart is a React-based e-commerce shopping interface created as a learning and practice project.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Vite

## Features
- Home page with product sections
- Product categories
- New collections section
- Popular products section
- Product details page
- Shopping cart interface
- Login and signup interface

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/shivani-0312/StyleCart-React.git
   ```

2. Navigate to the project folder:
   ```bash
   cd StyleCart-React
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
